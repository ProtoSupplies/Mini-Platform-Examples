# Mini-Platform-Examples
This repository includes demos or examples that have been created for the Mini Platform for Teensy 4.1

The Demo_Mini_Platform_Menus.ino example makes use of the TeensyUserInterface.h library for the menuing system.
It uses the fork by mjs513 which incorporates support for the ST7796 display used on this platform.
https://github.com/mjs513/TeensyUserInterface/tree/my_edits.
It compiles well under IDE 1.8.19, but sometimes throws duplicate font definition errors when compiled under IDE 2.3.10.
The .Hex is also provided to download it directly

The ESP32-C3 uses the ESP32_Demo_Mini_Platform.ino.
